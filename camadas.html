How it works

  1. 1Open the installer for your operating system.
  2. 2Choose the entire repository or one folder, then select where to save it.
  3. 3Git LFS retrieves the original files in the highest resolution available.

Before you start

The installer checks Git and Git LFS and offers assisted installation when possible. Git for Windows already includes Git LFS. An internet connection and sufficient disk space are required.

On Windows, the window now stays open if an error occurs. Photograph or copy the final diagnostic lines if you need support.

The menu reads the current repository each time, so newly added folders appear automatically.
