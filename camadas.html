How to download one layer

Recommended: download one layer at a time to receive the original file in full resolution.

  1. 1On the repository page, click the folder that contains the type of layer you need, such as Soil variables or Elevation.
  2. 2Inside the folder, click the name of the desired .tif file.
  3. 3On the file page, click the download arrow beside “Raw”. Your browser will save the original file.

How to download the complete repository

Use this route when you want all folders in a single ZIP archive.

  1. 1Return to the main repository page and click the green Code button.
  2. 2In the menu that opens, click Download ZIP.
  3. 3When the download finishes, extract the ZIP file to see the folders on your computer.
Recommended: download one layer at a time using the first guide. This gives you the original .tif in full resolution. A ZIP containing the entire repository may include small pointer files instead of the complete rasters.
